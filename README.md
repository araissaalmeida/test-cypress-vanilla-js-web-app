# test-cypress-vanilla-js-web-app
Repositório com testes end-to-end (E2E) para um site em JavaScript, criados com Cypress. | Repository with end-to-end (E2E) tests for a JavaScript website, created with Cypress.

passos para reproduzir: 
1. node.js instalado
2. IDE instalada
3. instalar as dependências (npm install)
4. rodar o projeto com npx cypress open
